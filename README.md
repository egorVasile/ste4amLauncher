# 🎮 st4amLauncher

Простой и быстрый Minecraft-лаунчер на Electron. Всё на русском: сборки, моды, модпаки — в пару кликов.

## ✨ Возможности

### 🗂️ Сборки
- Создавай сборки на любой версии Minecraft
- **Автоустановка загрузчиков**: Vanilla, Fabric, Forge, NeoForge, Quilt
- Импорт и экспорт сборок одним файлом (делись с друзьями)
- Импорт модпаков **`.mrpack` (Modrinth)** и **`.zip` (CurseForge)**
- Умное копирование модов между сборками — если мод уже скачан, он не качается заново
- Автоиконки: обложка мода становится иконкой сборки
- Своя иконка сборки (любая картинка)

### 🛒 Каталоги модов
- **Modrinth** — моды, ресурспаки, шейдеры, модпаки
- **CurseForge** — тысячи модов и модпаков, которых нет на Modrinth
- Фильтры по загрузчику (Fabric / Forge / NeoForge / Quilt) и версии игры
- Зависимости модов ставятся автоматически
- Избранное

### 📰 Лента новостей
- Новости лаунчера
- Патчноуты Java-версий Minecraft
- Фильтры по категориям

### 🛡️ Надёжность
- **Умная диагностика крашей** — лаунчер сам найдёт виновный мод и подскажет решение
- Все логи пишутся в файл — легко получить помощь
- Проверка файлов по контрольным суммам (sha1) — битые скачивания перекачиваются автоматически
- Автодоводка: если загрузчик не успел установиться — доустановится при запуске
- Автообновление лаунчера

### 🎨 Прочее
- Скины через **ely.by** (работают в игре без лицензии)
- Автоскачивание нужной Java
- Зеркала загрузки (официальный сервер + BMCLAPI)
- Настройка RAM, разрешения, JVM-аргументов
- Кастомизация интерфейса: светлая/тёмная тема, акценты, анимации

## 📥 Установка

1. Скачай последний установщик со страницы [Releases](https://github.com/egorVasile/ste4amLauncher/releases/latest)
2. Запусти `st4amLauncher-Setup-x.x.x.exe`
3. Готово — лаунчер обновляется сам

## 🚀 Быстрый старт

1. Введи ник
2. Выбери версию → «Играть» (Java скачается сама)
3. Или создай **сборку**: каталог → моды → установи → играй

## ❓ Частые проблемы

| Проблема | Решение |
|----------|---------|
| «Version not found» при запуске сборки | Обнови лаунчер до 3.0.7+ — загрузчик доустановится сам |
| Ошибка мода при запуске | Открой `logs/debug.log` и приложи к вопросу |
| Чёрный экран / краш графики | Обнови драйвер видеокарты |

Логи находятся: `%APPDATA%\.st4amlauncher\logs\debug.log`

## 🛠️ Сборка из исходников

```bash
npm install
npm run build        # установщик в dist/
```

Требуется Node.js 18+
